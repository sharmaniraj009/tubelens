TubeLens settings

Views, tags, publish date and the SEO score work without any setup. Likes, comments, engagement and subscriber counts need a free YouTube Data API v3 key.

  1. Open Google Cloud Console → APIs & Services → Library, and enable “YouTube Data API v3”.
  2. Credentials → Create credentials → API key. Restricting it to the YouTube Data API is recommended.
  3. Paste it below. It is stored only in this browser (chrome.storage.local).
