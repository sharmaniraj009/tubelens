Welcome to TubeLens

YouTube growth tools that run in your browser. Most of them work right away, with no setup.

  • Video panelA panel next to every video with views, views per hour, tags and a 100-point SEO check.
  • ClipsSee which moments viewers replay most, then mark, save and share clips for Shorts or highlights.
  • Toolbar popupKeyword ideas, an SEO checker for drafts, and all your saved clips. Click the TubeLens icon to open it.
  • Thumbnail makerStart a thumbnail from any video frame and preview it at YouTube's sizes.

Open YouTube and play any video to try it. Tip: pin TubeLens from the puzzle-piece menu so the popup is one click away.

Optional: a free YouTube API key

The key adds likes, comments, engagement and subscriber counts to the panel, and turns on Channel research (channel reports, competitor tracking and the outlier finder). It takes about 2 minutes:

  1. Open YouTube Data API v3 in Google Cloud and click Enable. Create a project first if it asks you to.
  2. Open Credentials, click Create credentials → API key, then copy the key.
  3. Paste it below and click Save and test.

The key is stored only in this browser and is sent only to Google. The free quota is 10,000 units a day: the panel uses about 2 per video, a channel report about 3, and each search 100.

Clip shortcuts

Use these on any video page, then open the Clips tab in the panel to see your clips.

Alt+[Set the clip start to the current time
Alt+]Set the clip end to the current time
Alt+SSave the clip

TubeLens doesn't download or cut videos. Use the saved times in your editor, or use YouTube's “Edit into a Short” on your own videos.

Your data

Clips, tracked competitors, drafts and settings stay in this browser's extension storage. TubeLens has no server and collects nothing.
